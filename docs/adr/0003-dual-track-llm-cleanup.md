# 实时 LLM 整理采用"双轨展示 + 默认隐藏原文"，而非原地替换

间隔整理（每 5-10s 把已冻结的原文片段发给 OpenAI 兼容 LLM 做去口语化/纠错/补标点）有学术背书（CARTGPT，ACM ASSETS 2024，面向听障人群），但**原地替换**已显示文本会因 flicker 显著伤害阅读（Google CHI 2023，123 人实验；听障用户对字幕的依赖是唯一且连续的，伤害更大）。因此采用双轨：原文不可变保留在后台作为事实来源，界面默认只显示整理版（阅读体验最优），提供一键按钮切换显示原文核对。并发防丢字/乱序采用"不可变片段 + editId 单调递增 + 单 writer + 只整理已冻结片段"。

- **Considered Options**: 原地替换当前行（被 Google CHI 2023 证据否决）；整理版只高亮改动词（CARTGPT 做法，作为整理版内部的差异提示叠加使用）；只替换已滚出视线的旧行。
- **Consequences**: 原文与整理版需并行存储与版本化；LLM 失败时保留原文并退避重试 3 次后放弃；单次输入 ≤500 字、滚动窗口 ≤2000 token 防上下文溢出。
